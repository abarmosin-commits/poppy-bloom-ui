# Poppy Bloom UI

Демонстрационный frontend: Vite, React, TypeScript, Tailwind CSS, React Router и Recharts. API Wildberries и Supabase не подключены.

## Запуск

Node.js 22.12+ (или 24 LTS).

```sh
npm install
npm run dev
```

`npm run build` проверяет TypeScript и создаёт production-сборку в `dist`. `npm run preview` запускает её локально. Хостинг должен перенаправлять маршруты приложения на `index.html`.

Mock-данные находятся в `src/data/mock.ts`, дизайн-токены — в `src/styles/tokens.css`. Работают Dashboard, Products, Advertising и Finance на mock-данных; Wildberries API и Supabase пока не подключены.

## Структура

```text
src/
  components/   # AppLayout, граница ошибок
  pages/        # Dashboard, общая заглушка остальных пространств
  data/mock.ts  # Синтетические данные за 1–14 октября 2026
  lib/format.ts # Русское форматирование валют и дат
  styles/       # tokens.css и стили layout
  App.tsx       # Маршруты
  main.tsx      # Точка входа
public/         # Статические файлы
```

## Маршруты и состояния

- `/` перенаправляет на `/dashboard`.
- `/dashboard`: сводка, 7/14 дней, график Recharts с табличной альтернативой, поиск и сортировка товаров.
- `/products`: каталог на mock-данных, поиск по названию/артикулу продавца/артикулу WB, статус, сортировка и пять показателей.
- `/products/:productId`: информация и показатели выбранного товара; возврат сохраняет URL-фильтры каталога.
- `/advertising`: рекламная аналитика на mock-данных с периодом 1/7/30 дней, поиском, сортировкой, разбивкой кампаний, деталями артикула, рекомендациями и состояниями loading/empty/error.
- `/finance`: финансовая сводка, расходы, динамика, операции, фильтры, сверка и состояния loading/empty/error на mock-данных.
- Неизвестный адрес показывает сообщение и ссылку на обзор.

На мобильном навигация раскрывается кнопкой; Escape закрывает её. Таблицы сохраняют столбцы и прокручиваются горизонтально. Все значения синтетические: продажи — цена товара × количество, в примере один товар в заказе. Отсутствующие расходы (`null`) не заменяются нулём. График, сводка и товары используют один период и одну выборку.

Токены реализованного интерфейса являются временной основой, а не извлечением из Figma: утверждённые макеты не предоставлены. При будущем подключении API mock-источник следует заменить явным слоем данных, сохранив состояния отсутствия и ошибок.

## Mock-каталог Products

`src/data/mockProducts.ts` содержит шесть вымышленных товаров, включая примеры нулей и неизвестных значений. Числовые артикулы WB не получены из API. Статусы: «В продаже», «Требует внимания», «Архив». Период фиксирован: 1–14 октября 2026.

Условная модель Products: один заказ = одна единица; выкуп — полученные единицы / заказы; продажи — выкуп минус возвраты; выручка — продажи × демо-цена без расходов. Это отдельное определение демо-показателей, не утверждённая методика Wildberries. Dashboard показывает стоимость товаров в демо-заказах, поэтому его денежный показатель не равен выручке Products. Неизвестные значения сортируются последними в обоих направлениях.
